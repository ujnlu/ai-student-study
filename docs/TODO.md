# 小学 1-5 年级家用作业辅导网站 · TODO

> 用途：自家孩子使用（单家庭、少量账号），不对外运营。
> 目标：提高成绩、辅导作业。核心链路借鉴作业帮 / 小猿AI / 学而思学习机 / Khanmigo：
> **拍照作业 → AI 批改 → 错题本 → AI 引导讲解（不直接给答案）→ 变式练习 → 学情报告**。
> 硬性要求：动态站点、有数据库、可配置 AI 助手、支持上传图片 / 拍照。
> 更新日期：2026-09-15。M1-M4 已实现，另加教材导入、同步练习、学情报告、激励体系；差距对照见 docs/COMPETITOR-GAP.md。

## 0. 技术选型（沿用你现有项目的栈）

- [x] **框架**：Next.js 16（App Router）+ React 19 + TypeScript + Tailwind 4，前后端一体，API 走 Route Handlers / Server Actions。
- [x] **数据库**：Prisma ORM。开发用 SQLite（零配置）；`DATABASE_URL` 一换即可切 PostgreSQL（Docker 起一个）。
- [x] **AI 接入**：Vercel AI SDK（`ai` 包）做统一抽象，Provider 在后台可配：
  - Anthropic Claude（默认，视觉能力强，适合批改手写作业）
  - OpenAI 兼容接口（DeepSeek / 通义 / 智谱 / Ollama 本地等，填 baseURL + key 即可）
  - 密钥存数据库时用 AES 加密，只在服务端解密。
- [x] **图片存储**：本地磁盘 `uploads/`（Docker volume），数据库存路径与元数据；后续可换 S3 / OSS。
- [x] **登录**：家庭内使用，做简单的家长 PIN 码 + 孩子选头像登录即可，不接第三方 OAuth。
- [ ] **部署**：`docker compose up`（app + postgres），家里 NAS / 云主机 / 本机均可；手机同一 WiFi 打开即用。
- [x] 前置：脚手架 `create-next-app`、Prisma 初始化、ESLint/Prettier、`.env.example`。

## 1. 数据模型（Prisma schema 初稿）

- [x] `Family` / `ParentSettings`：PIN、默认 AI 配置、每日时长上限。
- [x] `Child`：昵称、头像、年级、教材版本（人教/北师大/苏教）、当前学期。
- [x] `AiProvider`：名称、类型（anthropic / openai-compatible）、baseURL、加密 key、模型名、是否默认、温度等。
- [x] `AiAssistant`：一个"助手"= 一套提示词 + 绑定的 Provider + 角色（批改 / 讲解 / 出题 / 作文点评）+ 年级语气设置；可多个，可复制。
- [x] `Subject` / `Unit` / `KnowledgePoint`：学科 → 单元 → 知识点，含前置关系（自引用多对多）。
- [x] `Upload`：图片路径、类型（作业页 / 单题 / 试卷）、OCR 文本、AI 识别的结构化结果（JSON）。
- [x] `Problem`：题干、答案、解析、知识点、难度、来源（上传识别 / 题库 / AI 生成 / 程序生成）。
- [x] `Attempt`：孩子的一次作答（答案、对错、用时、错因标签）。
- [x] `MistakeBookEntry`：错题本条目（Problem + 状态：未讲解 / 已讲解 / 已消灭 + 下次复习时间）。
- [x] `Conversation` / `Message`：AI 讲解对话记录（家长可回看）。
- [x] `Mastery`：child × knowledgePoint 的掌握度分数、更新时间。
- [x] `DailyPlan` / `StudySession`：每日任务与学习时长记录。

## 2. 核心功能

### 2.1 上传 / 拍照（第一优先级）
- [x] 上传组件：手机端用 `<input type="file" accept="image/*" capture="environment">` 直接调相机；桌面端拖拽上传；支持多张。
- [x] 前端压缩（长边 ≤ 2000px，JPEG）后再传，减少 token 与流量。
- [x] 服务端：校验类型/大小 → 存 `uploads/{childId}/{date}/` → 写 `Upload` 记录 → 入队做 AI 识别。
- [ ] 裁剪 / 旋转 / 选题目区域（可选，后期）。

### 2.2 AI 批改
- [x] 把图片发给视觉模型，要求输出**结构化 JSON**：每道题的题干、孩子的答案、正确答案、对错、涉及知识点、错因猜测。
- [x] 批改结果页：逐题展示，可手动改判（模型看错时），确认后错题自动进错题本。
- [ ] 口算专用模式：只判对错、速度快、统计正确率与用时。
- [ ] 作文 / 语文题：给出六维度点评（内容、结构、语言、书写、错别字、亮点），不直接改写。

### 2.3 AI 引导式讲解（差异化核心）
- [x] **一键动画讲解**：AI 生成 4-6 步分步讲解（每步 SVG 画面 + 旁白），自动配语音逐步播放，结尾附方法小结和一道小练习；批改结果、错题本、练习结果页均有入口。
- [ ] 讲解画面升级：接入图片生成模型做情境配图（可选）；导出为真正的 mp4 视频（可选，价值不大）。
- [x] 系统提示词按角色 + 年级分级：1-2 年级口语化、多打比方；4-5 年级可以用术语。
- [x] 苏格拉底式流程：先问"你是怎么想的" → 一步一停 → 孩子答对了再往下 → 最后让孩子自己说出答案。
- [x] 家长可开关"直接看解析"。
- [x] 讲解上下文自动注入：本题、知识点、前置知识点掌握度、最近同类错题。
- [x] 流式输出（AI SDK `streamText`），并附一个"懂了 / 没懂"按钮记录反馈。
- [x] 讲完自动生成 2-3 道**变式题**，做对后错题标记"已消灭"。
- [x] 语音：题目朗读（浏览器 `speechSynthesis` 先顶上，后期换 TTS）；语音输入（Web Speech API）。

### 2.4 错题本与复习
- [x] 错题本列表：按学科 / 知识点 / 日期筛选，状态流转（未讲解 → 已讲解 → 已消灭）。
- [x] 间隔复习：消灭后按 1 / 3 / 7 / 15 / 30 天再推一次变式题，错了重置。
- [ ] 一键导出错题为打印版 PDF（周末重做）。

### 2.5 练习与出题
- [x] 口算生成器：按年级规则程序化出题（加减乘除、进退位、竖式、单位换算），可选题量与限时。
- [x] AI 出题：按知识点 + 难度生成同步练习，先入"待审核"，家长看一眼再给孩子。
- [ ] 语文：生字听写（TTS 读词，孩子写完拍照批改）、古诗背诵（语音识别比对）。
- [ ] 英语：单词拼写、课文跟读（后期）。

### 2.6 AI 助手配置后台（家长端）
- [x] Provider 管理：新增 / 编辑 / 测试连通 / 设默认；key 加密存储，页面只显示尾号。
- [x] 助手管理：角色、提示词模板（带变量：`{grade}`、`{subject}`、`{knowledgePoint}`、`{mastery}`）、绑定模型、温度、最大 token。
- [x] 每个功能（批改 / 讲解 / 出题 / 作文）可分别指定助手，例如批改用 Claude、口算讲解用便宜的本地模型。
- [x] 提示词版本记录，可回滚；用一组固定测试题（20-30 道）跑"讲解质量"对比。
- [x] 用量统计：按天 / 按助手统计 token 与费用。

### 2.7 学情与家长端
- [x] 孩子首页：今日任务（新错题 N 道、复习 N 道、口算 1 组）、连续打卡、进度地图。
- [x] 家长看板：每周正确率趋势、薄弱知识点 Top 5、掌握度雷达、学习时长、AI 对话回看。
- [x] 家长设置：每日时长上限、可用时段、教材版本、切换孩子。

## 3. 学习科学（第二阶段）

- [x] 知识图谱：先手工录入 1-5 年级数学（人教版）单元 → 知识点 → 前置关系，约 300 个节点，做成 seed 脚本。
- [ ] 掌握度模型：每知识点 0-100 分，做对 +、做错 −，权重随难度与时间衰减；连续 3 次对且间隔 ≥ 3 天视为掌握。
- [ ] 前置回溯：某知识点连续错 2 次 → 出前置知识点的诊断题 → 先补前置。
- [ ] 自适应难度：把正确率维持在 70-85%。
- [ ] 隐式复习：高阶题做对时，顺带刷新其前置知识点的掌握度。

## 4. 儿童体验

- [x] 大按钮、少文字、每屏一件事；1-2 年级默认开启朗读。
- [x] 即时反馈：对了有音效动画，错了不扣分只给提示。
- [x] 进度地图 + 打卡做习惯层，奖励只解锁头像 / 贴纸，不做"打完游戏才能学"。
- [ ] 平板 / 手机横竖屏适配；护眼配色；到时长自动提示休息。

## 5. 工程与运维

- [ ] `docker-compose.yml`：app + postgres + volume（uploads、db）。
- [ ] 每日自动备份数据库与 uploads 到另一块盘 / 网盘。
- [x] AI 调用统一封装：重试、超时、结构化输出校验（zod）、日志。
- [ ] 基础测试：口算生成器、掌握度计算、提示词模板渲染。
- [ ] 手机上用 PWA（添加到主屏幕，全屏打开）。

## 6. 里程碑

| 阶段 | 周期 | 交付 |
|---|---|---|
| M1 骨架 | 1 周 | Next.js + Prisma + 登录 + 孩子/家长两端框架 + AI Provider/助手配置后台（含连通测试） |
| M2 拍照批改 | 1-2 周 | 上传/拍照 → AI 结构化批改 → 结果页手动改判 → 错题本 |
| M3 引导讲解 | 1-2 周 | 流式苏格拉底讲解 + 变式题 + 懂了/没懂反馈 + 对话回看 |
| M4 练习与复习 | 1-2 周 | 口算生成器、AI 出题审核、间隔复习、每日任务、打卡 |
| M5 学情与知识图谱 | 2 周 | 数学知识点 seed、掌握度、前置回溯、家长看板 |
| M6 语文/英语与语音 | 按需 | 听写、古诗背诵、单词、TTS/ASR |

先跑通 M1-M3 就能每天用起来，M4 之后按孩子实际情况再排。
